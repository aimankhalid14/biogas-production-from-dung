# Biogas Production from Dung

## Overview

This repository contains the documentation of an academic biotechnology project focused on producing renewable biogas from animal dung using the anaerobic digestion process.

The project demonstrates the design of a simple laboratory-scale biogas generation system where organic waste is converted into methane-rich biogas under oxygen-free conditions.

## Objectives

Design a small-scale biogas production setup.
Produce renewable biogas from animal dung.
Study the biological stages of anaerobic digestion.
Understand the environmental factors affecting methane production.
Promote sustainable waste management and renewable energy.

## System Components

Airtight digestion container
Gas outlet pipeline
Three-way gas distribution connection
Tyre tube for gas storage
Gas release outlet for utilization

## Working Principle

The project uses anaerobic microorganisms to decompose organic matter in the absence of oxygen. During digestion, complex organic compounds are converted into methane (CH₄), carbon dioxide (CO₂), and trace gases.

The digestion process consists of four stages:

1. Hydrolysis
2. Acidogenesis
3. Acetogenesis
4. Methanogenesis
